SHAWN TILE: INSTALL ON ANOTHER MAC

Requires macOS 13 Ventura or later. Includes Apple Silicon and Intel code.

1. Drag Shawn Tile.app into Applications (or your own ~/Applications folder).
2. Open it. This personal build is ad hoc signed, not Apple notarized.
   If macOS blocks it, open System Settings > Privacy & Security and choose
   Open Anyway for Shawn Tile, then confirm Open. On newer macOS a right-click
   Open alone may not suffice. Do not disable Gatekeeper globally.
3. In the app, click Open permission settings and enable Shawn Tile under
   Accessibility (called Device Control & Data Access on newer macOS).
   Each Mac needs its own grant. If absent, use the + button to add the app.
4. Turn on Automatic tiling. Use the rectangle icon in your menu bar for
   layouts, settings, pause, window selection, and quit.
5. Optional: General > Open at login. Approve Login Items if macOS requests it.

Control-Option-Command + 1/2/3/4: maximum tiles on active display
Control-Option + Z: focus/restore
Control-Option + F: float/tile active window
Control-Option + `: cycle windows sharing the active tile
Control-Option + arrows: swap neighboring tiles
Control-Option + Return: make primary
Control-Option + [ or ]: previous/next window
Control-Option + P: pause/resume

Customize these in Settings > Keyboard. Click an action's shortcut, choose its
modifiers and key, then Save. You can disable individual actions, use the default
for one action, or Restore Defaults for all shortcuts. Changes persist locally.
Include Control or Command. Key names use US keyboard positions. Duplicate or
unavailable combinations show an error and keep the previous working bindings.
For remote use, Screen Sharing preset uses Control-Shift-Command with each
action's usual key, including P for pause/resume. You can edit any binding after
applying the preset, or Restore Defaults to return to the original combinations.

Pause before using Stage Manager, native edge tiling, or another window manager.
Automatically fit windows is on by default. Shawn Tile adjusts split sizes and spacing to the minimums your windows accept.
Grid, Rows and Columns keep the selected shape; Auto can change arrangements. If fewer tiles fit, it stacks
extra windows; more tiles return when room opens up. Your tile count is a maximum.
Tidy now forgets learned minimums and retries. A window too large for the whole
display is centered and reported separately. General > Pause and restore pre-tiling positions
restores still-visible windows from this session.

Updates (0.4.1 and newer): use Check for Updates in the menu or General settings.
A new-release banner shows features; Update & Restart downloads, verifies,
backs up and replaces the app. Daily checks can be turned off in General.
Install 0.4.1 manually once if you have an older version without these controls.
Read-only DMG copies must first be moved to Applications or ~/Applications.
For manual updates, quit the old app, replace it at the same location, and reopen. Ad hoc
signatures can require re-granting Accessibility after a rebuild. Remove and
re-add the app in System Settings if an old grant no longer works.

For free local updates that preserve one signing identity, follow:
https://github.com/swright7001/shawn-tile/blob/main/docs/LOCAL-SIGNING.md
After that setup, use scripts/install.sh for downloaded updates instead of
dragging an ad hoc release over the locally signed app. Keep your private key on
your own Mac; do not share it with friends.

Uninstall: quit; disable Open at login; remove the app; remove its Accessibility
grant. Preferences are in defaults domain com.shawnwright.ShawnTile.

IF THE PERMISSION IS ON BUT THE APP STILL ASKS

A previous build can leave an enabled entry that no longer matches the installed
app's signature. Turning the old entry on is not enough in that case.

1. Quit Shawn Tile using its menu-bar icon (closing Settings alone does not quit).
2. In Privacy & Security > Accessibility / Device Control and Data Access,
   select Shawn Tile and remove its entry using the minus / Remove button.
3. Click Add (+) and select the exact installed Shawn Tile.app. For an install
   made by scripts/install.sh, press Command-Shift-G in the file picker and enter
   ~/Applications/Shawn Tile.app. A DMG install may instead be /Applications.
4. Enable that newly added entry, authenticating if macOS asks.
5. Reopen that same installed app and enable Automatic tiling.

Do not add the copy inside the DMG or a temporary build folder. Do not rebuild or
replace the installed app between granting permission and reopening it. Ad hoc
signed builds can need this refresh after an update. A new permission grant
must come from the user; the application cannot bypass macOS's check.
